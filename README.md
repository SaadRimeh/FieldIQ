# FieldIQ Platform

FieldIQ is a comprehensive Field Force Management Platform.

## Repository Structure

- **`FieldIQ_Microservices/`**: Core Backend Microservices (Node.js, Express, TypeScript, Prisma, Socket.IO, Redis, RabbitMQ)
- **`FieldIQ_App/`**: Mobile / Client Application
- **`FieldIQ_Dash/`**: Admin & Manager Dashboard
- **`FieldIQ_FastApi/`**: FastApi Services
